An UPnP Audio Media Renderer based on MPD@macOS

Install upmpdcli with the following command:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/sam0402/Homebrew/refs/heads/main/upmpdcli/install_upmpdcli.sh)"
```

Uninstall upmpdcli with the following command:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/sam0402/Homebrew/refs/heads/main/upmpdcli/uninstall_upmpdcli.sh)"
```
